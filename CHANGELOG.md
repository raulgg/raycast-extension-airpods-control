# AirPods Control Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Set the listening mode to Noise Cancellation, Transparency, Adaptive, or Off with the [airpods-control](https://github.com/raulgg/airpods-control) CLI
- Cycle through the listening modes you select, skipping modes your AirPods do not support
- Toggle Conversation Awareness
- Show the current listening mode and Conversation Awareness state in command subtitles, confirmed by macOS
- Refresh AirPods status manually or in the background about once a minute
- Confirm each change with a toast, or a HUD when the Raycast window is closed
- Install, update, or repair the CLI from Raycast with the Manage AirPods Control CLI command, including Homebrew installation with one action
